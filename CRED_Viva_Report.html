11 — Viva Q&A cheat sheet (24 × 2-line answers — 21–24 added per review)

1. Did you use Python to read the PDF?Yes — pypdf for page count/meta + pdfplumber for clean 10-page text (§0 code). Reproducible, no manual copy.
2. Is 11% real?No. Raw +11.03% → per-day +0.29%, Welch p=0.93, perm p=0.93, boot CI [−6.1%,+6.8%] — not distinguishable from zero. Per-row +0.8%, funnel flat.
3. Prove calendar effect.Feb ₹170.14M/28=₹6.076M/d; Mar ₹188.91M/31=₹6.094M/d. 31/28−1 alone predicts +10.7%.
4. Biggest DQ issue?Entity collisions (borrowers 30.6k→11k, agents 30k→1k) + TXN reuse 4,297 + 50% timestamp inversions. Money impact −₹2.9 Cr.
5. Why SUCCESS only?FAILED/PENDING/REVERSED aren't cash. Including them overstates recovery and rewards retries.
6. Why ignore payment_reference?Same TXN on different accounts/amounts (e.g. TXN…0032 ×3). Not unique — payment_id is.
7. Timezone handling?Parse source tz → UTC → IST; bucket day/hour in IST. Stored strings showed no shift bug, but pipeline enforces it.
8. Agent tenure?MIN(joined_at) per agent_id; name has 10 values for 1,000 agents — unusable.
9. PTP kept definition?Validated cash within +7d of promised_date, not status flag (93.5% OPENs stale).
10. Contact rate?ANSWERED/deduped calls, IST day. Flat 19–20% — no dial improvement.
11. Simpson's paradox here?Overall +11% up but every stratum flat (per-day, per-row, funnel). Aggregate misleads.
12. Survivorship bias?Stale OPEN PTPs + lingering PAID/CLOSED inflate “success”; 6,656 never-targeted hidden from denominator.
13. Selection bias?Targeted pool non-random (22% never touched); compare per-eligible, not per-targeted.
14. Attribution window?7-day contact→payment; 30-day/last-touch over-credits Mar by ~3pp (more rows, more chance matches).
15. Vendor change?No — versions ~33% every month, all codes present. Rules out definition shift.
16. Counterfactual design?PSM + DiD (new-targeting vs matched legacy), parallel trends, placebo cutover, window sensitivity. Currently weak first stage → need prospective A/B.
17. Why targeting over agents? (REVISED)Not “untouched pool” (never 43.69% beats targeted 43.05%, p=0.35) — but zero-signal scoring (H, p=0.345) + zero stratified lift (−0.65pp) + 4,128 stale PTPs. Fix scoring via capped experiment; cheapest + reversible.
18. ROI math? (REVISED — scenarios)Empirical 0 (p=0.35); base 3–5% ≈ ₹3.8–6.3Cr/yr, 2–4×, BE 3–5mo (assumption); upside 8–12% ≈ ₹10–15Cr holdout-gated. Cost ₹1.2Cr + 50% split are assumptions. Old “6–9Cr/5–7×/65%” retired.
19. Confidence? (REVISED)High on flat (per-day p≈0.93, targeted-never p≈0.35, priority p≈0.35); low on any pre-holdout lift. Cost/volume are estimates — say so.
20. Production guard?Per-day KPIs + PK lineage + 3-day re-state + z-score/flat-rate guards so next false +11% pages instead of ships.
